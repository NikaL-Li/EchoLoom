# 译诊 P1–P4 整合审查报告

- 日期：2026-11-24
- 范围：P1 外壳/首页/集成、P2 场景与常用语、P3 对话/声音/大字牌、P4 记录/我的/权限
- 产物：`译诊/ios/Yizhen.xcodeproj`（同时保留 `ios/project.yml`）
- 结论：四个模块已合入同一个 iOS 17+ / SwiftUI 工程；静态校验通过。**当前 Linux 环境没有 Xcode 与 SwiftUI 运行时，因此尚未执行真正的 Xcode 编译、模拟器运行和真机语音测试。**

## 1. 合并策略

四份 zip 不能直接叠加，因为存在大量同名但语义不同的共享层。最终采用「P4/P1 外壳 + P2 数据 + P3 能力」的统一方案：

1. 以 P4 的 `ios/Yizhen`（P1 最新版 + P4 页面）作为 App 外壳。
2. 把 P2 的 `FeatureScenes` 源码并入 `Features/Scenes`，不再作为独立 SPM 包；场景数据成为唯一数据源。
3. 把 P3 的语音识别、播报、大字牌实现保留，对话页按统一状态层重写；P3 的独立主题和独立状态层不再保留。
4. P4 的 `YizhenCore` 独立包不直接引入，保留其会话 JSON 存储/统计思路并在 App 内实现，避免一个工程出现两套 `YZSession`。
5. 根工程由一个 `RootView` 统一管 Tab、路由、主题、紧急大字牌和会话存储。

这样做的直接收益是：只有一个 `YZTheme`、一个 `YZAppState`、一个 `YZSession`、一个 `YZScene`，首页、对话、记录、我的读同一份数据。

## 2. 主要冲突与解决

| 冲突 | 处理 |
|---|---|
| P1/P4 `enum YZTheme`（静态资源色）与 P3 `struct YZTheme`（Environment Token）同名 | 保留 P1/P4 静态主题；删除 P3 Token 主题；P3 的语音/大字牌改为统一主题 |
| P1 `YZAppState`（turns/session/设置）与 P3 `YZAppState`（messages/scenes/phases）不兼容 | 以 P1/P4 状态为准，重写 `TalkView`；P3 的 `YZMessage`/`SceneNavContext` 不再进入工程 |
| P1 `enum YZScene` 与 P2 `SceneKind` 重复 | `typealias YZScene = SceneKind`，P2 数据作为唯一场景源 |
| P1 `YZTerm` 与 P2 `Term` 重复 | `typealias YZTerm = Term` |
| P1 `YZPhraseStoring`（load/save map）与 P2 `YZPhraseStoring`（customPhrases/add/update/delete）同名 | P2 协议重命名为 `YZCustomPhraseStoring`，实现为 `YZUserDefaultsPhraseStore` |
| P1 `YZSessionStoring`（load/save array）与 P2 场景切换协调器的 `YZSessionStoring`（save one）同名 | 不引入 P2 独立协调器；场景切换由 `YZAppState` 直接完成，使用 P1/P4 的会话存储协议 |
| P2 `SceneNavBar` / `SayList` 与 P3 同名组件 | 保留 P2 版本（数据完整、支持步骤条/下划线标签），对话页直接使用 |
| P3 `TalkView` 依赖 P3 的 message/scene/theme/state | 按统一 `YZTurn`、`SceneKind`、`YZTheme` 重写对话页；复用 P3 的 `SpeechService`、`SpeechPlayer`、`SignView` |
| P4 `YZProfileSettingsPersistenceModifier` 用 `.id` 重建根视图 | 删除该 modifier；RootView 负责把设置写入 `YZThemeRuntime`，只重建 Tab 内容，不丢路由 |
| P4 `YZDefaultSessionSummaryProvider` 返回 `.unavailable` | 改为调用统一 `YZSummaryBuilder`，会话详情和对话页共用同一套要点算法 |

## 3. 模块审查与修复

### 3.1 P1：外壳、设计系统、首页

已修复/加固：

- **字体自适应**：原 P1 字体是固定 `Font.system(size:)`，不随系统动态字体变化。现在 `YZTheme.font(...)` 用 `UIFontMetrics` 叠加用户 18/24/30 档位，并设置保护性上限，避免大字号破版。见 `ios/Yizhen/Shared/YZTheme.swift:129`。
- **全 App 主题切换**：RootView 在每次绘制前写入运行时字号/高对比，并用稳定 revision 只重建 Tab 内容；主题切换不会把整个路由和 Talk 状态一起重置。见 `ios/Yizhen/RootView.swift:11`。
- **iPad 居中**：所有页面内容经 `.yzContentWidth()` 限制 430 并居中；Tab 栏宽度限制 458（内层 430 + 边距）。见 `ios/Yizhen/RootView.swift:40`、`Shared/YZTheme.swift:177`。
- **首页布局**：问候、今日对话、大图、两个入口、更多入口全部保留；大入口改成自适应网格（窄屏自动一列，正常 430 宽度两列），避免大字号挤破。
- **Hero 占位图**：四个 hero imageset 原来只有 Contents.json，没有图片，运行会依赖渐变兜底。现在生成 4 组柔和渐变占位图（1x/2x/3x），并保留加载失败时的渐变兜底；后续可直接替换成团队照片。
- **高对比首页**：高对比时 Hero 关闭图片/渐变，改为白底黑字黑边；两个大入口、Tab、卡片都去阴影并加黑边。
- **安全区/底部留白**：页面底部保留 112，Tab 悬浮在安全区上方；对话页改用 `safeAreaInset` 底部 Dock，避免写死 82/138 在刘海屏和小屏上错位。
- **状态栏/大字牌**：紧急大字牌隐藏状态栏；会话详情的大字牌改用 `fullScreenCover`，不会再被悬浮 Tab 栏压住。见 `ios/Yizhen/RootView.swift:49`、`Features/Records/SessionView.swift:97`。
- **动效**：Tab/路由 0.12 淡入、首页区块 40ms 依次上浮、消息 0.18 上浮、Hero 6 秒缓慢放大，均尊重「减少动态效果」。

### 3.2 P2：场景与常用语

- **场景数据完整**：最终数据为 5 场景、20 环节、120 条内置句、110 条唯一术语；就医 70 条术语，其余各 10 条，环节内句子无重复。见 `Features/Scenes/SceneCatalog.swift`。
- **导航统一主题**：P2 原来的 `SceneTheme` 只读取 `ColorScheme`，不响应字号/高对比；现在映射到 `YZTheme`，并在高对比下使用白底黑边、选中反色。见 `Features/Scenes/SceneNavBar.swift`。
- **点击区域**：场景胶囊、步骤点、下划线标签、可播句、添加按钮、会话行都补到至少 44pt；视觉尺寸仍保持设计值。
- **常用语只发到正确环节**：原先「我的常用语」点句子只回传文字，Talk 会停留在 AppState 当前环节。现在回调携带 `selectedSub`，并由 `startTalk(withPhrase:subScene:)` 设置本次对话环节。见 `Features/Scenes/PhrasesView.swift:207`、`Shared/YZAppState.swift:103`。
- **自定义句持久化**：UserDefaults JSON，按 `场景|环节` 分组；空、重复、超过 60 字都有错误提示；内置句不可编辑/删除。保存/编辑/删除后通过 `onStoreChanged` 刷新首页和「我的」条数。
- **术语提示**：`TermMatcher` 取最长匹配；输入抽屉显示匹配项，对话中最新一条对方消息下方显示提示条；只提示，不改用户文字。
- **场景切换**：切场景先保存当前会话，再清空对话、切默认环节、插入「— 场景 · 环节 新会话 —」分隔条；切环节只换句子/术语并去掉分隔条。空对话时也保留分隔条（已单独处理）。
- **已播计数**：点句后 `SayList` 自己记录「已播 N 次」，同时把该句写入对话并播报；重复点同一句不会重复插入会话，只更新最后一条“我”的状态。

### 3.3 P3：对话、声音、大字牌

- **完整对话页**：顶部关闭/标题/面对面、场景导航、对话/常用语分段、生成要点、消息流、临时识别卡、紧急条、三按钮 Dock、输入抽屉均已接线。见 `Features/Talk/TalkView.swift`。
- **状态统一**：P3 的 `YZMessage` 不再存在；对话消息、会话详情、记录页都使用同一个 `YZTurn`/`YZSession`。
- **权限弹窗中断 Bug（重点修复）**：系统麦克风/语音识别授权会让 App 短暂进入 `.inactive`。原实现如果在 inactive 就停音频，会在授权弹窗出现的瞬间停掉正在申请的听写，用户允许后也不会开始。现在只在 `.background` 或非授权状态下的 `.inactive` 停止。见 `Features/Talk/TalkView.swift:91`。
- **权限失败文案**：麦克风被拒和语音识别被拒现在分别给出正确文案，不再把“语音识别未授权”说成“麦克风未授权”。见 `Features/Talk/SpeechService.swift:31`。
- **关闭/切场景不丢最后一句**：`flushSpeech()` 会先停听写，把 `SpeechService.stop()` 产生的最后一段临时文本写入会话，再关闭或切场景，避免“正在听时点关闭”丢掉最后一句。见 `Features/Talk/TalkView.swift:803`。
- **播放状态**：发送、可播句、重播统一先置「已播报」，失败回调改为「播报失败」；全程文字模式置「文字直达」，不启动语音合成。避免快速连点时上一句永远停在「播报中」。
- **互斥与打断**：听写与播报互相停止；打开输入、切换场景、切后台、来电/路由变化都会停止；`SpeechPlayer` 自带超时和 delegate 清理。
- **大字牌**：复用并修正 P3 的 `SignView`；竖屏从 160 自动缩到 72，横屏单行横滚；点击任意处退出；禁用自动锁屏；高对比下提示文字变黑；全屏覆盖层级高于 Tab。
- **面对面**：上下分屏、上面旋转 180°、各自过滤消息、新消息自动滚到底；底部保留听/说/全屏。
- **要点**：同一 `YZSummaryBuilder` 供对话页和会话详情使用；最多 3 条、每条 70 字、复制为带序号文本；无内容给出「暂无可归纳的内容」。
- **录音光边**：补齐 P1 设计要求的左右蓝色呼吸光边，听写时出现，停止/失败消失，高对比和减少动态效果下关闭。见 `Features/Talk/TalkSupport.swift:242`。
- **滚动 ID 统一**：消息卡片与自动滚动统一改用 `UUID.uuidString`，不会出现滚动到错误卡片或临时卡不跟随的问题。
- **空对话与文字模式**：空状态会按「全程文字」显示不同提示；切换场景后的空对话仍显示新会话分隔条。见 `Features/Talk/TalkView.swift:416`。

### 3.4 P4：记录、我的、指南

- **累计次数修复（重点）**：原实现用 `max(savedTotalCount, sessions.count)` 维护累计，记录被裁剪到最近 20 次后“累计”最多只会显示 20。现在 `YZAppState` 每次真正提交会话时累加 `totalSavedCount` 并持久化；会话文件只保留最近 20 条，累计仍准确。见 `Shared/YZAppState.swift:197`。
- **统计口径**：首页「今日对话」和记录页「今天」都使用 `todaySessionCount`，按 `Calendar.current` 本地时区计算；近 7 天、本月基于保留的最近 20 条，页面底部已注明「只保留最近 20 次」。
- **存储安全**：JSON 改为原子写入；写失败保留旧文件；读取失败返回空数组；记录目录设置 `isExcludedFromBackup`，避免「只保存在这台设备」被 iCloud 备份。见 `Features/Records/YZFeatureSessionStore.swift:30`、`:49`。
- **会话详情**：
  - 大字显示原来只是普通大字号面板，现改用真正的大字牌 `SignView`（含横屏、自动缩放、防锁屏）。
  - 要点占位改为真实 `YZSummaryBuilder` 结果。
  - 新增「导出文字」`ShareLink`，输出完整时间/场景/每句谁说的纯文本，可通过系统分享保存或复制。见 `Features/Records/SessionView.swift:61`。
  - 句子卡沿用 P3 左右蓝/绿边和状态显示，只读，点开看大字。
- **我的页**：用户卡、常用语条数、使用指南、外观三段、18/24/30、高对比、全程文字、版本号全部保留；增加「高对比会强制浅色背景」的说明，避免外观选择看起来失效。见 `Features/Profile/YZProfileComponents.swift:93`。
- **设置持久化**：删除原先把 `.id` 加在根视图上的 modifier；改为 RootView 监听四项设置并写 UserDefaults；App 启动时加载。高对比/字号变化只重建 Tab 内容，不重置路由。
- **新老模型统一**：删掉 P4 `YizhenCore` 中与 App 重复的 Session 模型/SPM 依赖；保留并重写本地 JSON 存储实现，避免工程出现两套会话类型。
- **GuideView**：修正指南步骤为当前真实 UI（常用语在对话页分段里，一键亮牌在首页，对话页叫「全屏」）；权限页只列麦克风/语音识别，首次使用才申请，从设置回来刷新。
- **自适应**：记录/我的/指南/会话详情全部加 430 最大宽度和 iPad 居中；我的页字号行用 `ViewThatFits` 在窄屏自动堆叠；权限行同样。

## 8. 已知取舍与剩余风险

1. **未编译**：这是最大风险。当前运行环境是 Linux，没有 Xcode/SwiftUI 运行时，只能做语法、类型名、资源、工程结构级静态检查。请在 Xcode 16 中编译；如出现编译错误，优先检查 `TalkView.swift`、`RootView.swift`、`YZTheme.swift`、`SceneNavBar.swift` 的 SwiftUI API 版本差异。
2. **真机语音**：模拟器对中文连续识别支持有限；`SpeechService` 的自动重连、权限、音频会话打断必须在真机验证。
3. **横屏输入**：大字牌横屏做了专门适配；对话页整体可滚动，但横屏+键盘同时出现时输入抽屉可能偏紧凑（横屏优先用于亮牌）。
4. **统计口径**：会话文件按需求只保留最近 20 次，所以「近 7 天/本月」只统计这 20 条；「累计」用独立计数保持准确。这是在“最多 20 条”约束下的明确取舍。
5. **动态字体上限**：字体按系统动态字体和用户档位放大，但设置保护性上限避免按钮/Tab 严重破版；极端无障碍字号下仍建议真机走查。
6. **写盘失败提示**：短语保存失败有弹窗；会话 JSON 写盘失败按原 P4 要求“保留旧文件、不崩溃”，没有额外弹窗；如需强提示可把存储协议改为 `throws` 并接 Toast。
7. **素材**：hero 占位图为自绘渐变，AppIcon 为 P4 提供的占位图；替换真实团队照片/品牌图标后观感会更好。
8. **无云同步/账号**：与 P4 设计一致，记录和常用语只在本机；未接任何第三方 SDK。
9. **无自动化测试 target**：原 P2/P3 独立包的测试依赖旧模型/Token 主题，直接搬入会制造第二套契约；本次先交付可运行工程。建议下一步为 `SceneCatalog`、`YZSummaryBuilder`、`YZRecordsStatistics`、`YZPhraseStore` 加纯逻辑测试 target。
