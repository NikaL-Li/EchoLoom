# 译声

为听障人士的日常沟通设计的原生 iPhone 应用。最低系统版本 iOS 18.2，版本 3.0（构建 15），独立标识 com.ylct.universal。可与骑手版共存，两者的本地资料互不影响。

| 入口 | 功能 |
| --- | --- |
| 沟通 | 面对面字幕、打字播报、双方静音打字、翻转展示、沟通卡、电话辅助 |
| 场景 | 购物、餐饮、出行、住宿、就医、窗口办事、工作学习、自定义；填写问题、地址、电话或编号，可收藏模板、保存准备、核对后打开地图或拨号、带着资料开始对话 |
| 常用语 | 收藏、分类、自定义、拖动排序；面对面输入区常驻快捷回复 |
| 我的 | 选择沟通偏好、查找已保存的对话、调整外观、重看引导、查看权限和系统字幕说明；骑手场景默认关闭 |

## 语音与隐私

手动输入使用系统语音；静音交流不录音、不播报。内置 9 条通用回复及 7 条骑手专用回复，共 32 个男女声 WAV 随包提供。新增或修改自定义回复会将这句文字发往 MiMo 合成服务；两种声音都保存成功后提示完成，不自动试听。之后播放使用本地文件，无需再合成。

场景和对话文字需用户主动保存，可在本机删除。应用不保存现场或通话录音，也不读取通话对端语音。电话辅助的播放取决于实际通话、设备及系统设置；系统字幕由 iOS 提供。

## 开发与检查

在本目录打开 译声.xcodeproj，选择 译声 和 iPhone 模拟器运行。UITesting.xcodeproj 的 ConversationChecks 包含通用版交互测试，UniversalFlowUITests 覆盖关键旅程。原骑手版历史验收资料保留在 Tests 中。

不连接设备也可编译生产工程：
```sh
xcodebuild -project 译声.xcodeproj -scheme 译声 -configuration Release -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build
```

包内音频清单位于 Tests/BundledReplyManifest.json。维护者可运行 python3 Tests/prepare_bundled_replies.py 在本地检查资源。模拟器可验证资料保存、文字往返、播放状态与外部跳转请求；环境噪声下的字幕质量、实际通话注入和对端听感需在真机验证。


## 2.1：电话开场和沟通首页

面对面默认「打字播报」，另有「实时字幕」「双向打字」。调整默认模式会记住选择，在对话内切换只影响本次。2.1 版首页的三幅风景均在本机绘制，可手动切换或停止轮换；系统减少动态效果时只手动切换。

「电话辅助 → 拨号与联系人」支持从系统通讯录选取具体号码，也可直接输入。「我的 → 通话开场与常用联系人」可设置通用开场、1–8 秒延迟及每个号码的专属开场。新句子沿用常用语双声生成流程。只在明确开启后、从此拨号页确认的外呼自动开场。普通拨号与来电不触发。先观察到新外呼，再观察接通，同时检查注入可用；不会把拨号跳转当接通，不判定接听者是人还是语音信箱，也不能确认远端实际听到。遇到多路通话、保留、结束、后台执行超时或错过窗口会取消。拨号页仍可在单路通话已接通、注入可用时手动播报。

通话状态来自系统 CallKit，系统不提供远端号码。联系人匹配来自拨号前选择的号码。通讯录选择使用系统选择器；不请求全库权限。真机验收应分别验证蜂窝外呼、取消、未接、接通、后台、保留、挂断与对端听感。

## 2.2：首页天气、Bing 风景与场景路线

首页优先展示 Bing 风景，可在图片右上角切换图片、停止轮换，或关闭联网壁纸。下载成功后会在本地缓存；没有缓存且无法联网时使用本机风景。天气位于两个沟通快捷入口下方，点开可查看城市来源、预报和发布时间，或主动选择「使用当前位置」。默认按网络参考城市展示，不主动请求定位。更新失败时保留上次天气并提示。

有地址或地点的已保存场景，在场景列表直接显示独立的「路线」按钮。点开会先显示目的地，选出行方式后再打开系统地图；也可只复制地址。在编辑页或沟通资料中仍能打开同样的导航选项。

## 2.3：沟通首页

天气位于首页标题右侧。面对面入口和默认模式位于风景卡下沿；快捷沟通区提供双方打字、电话辅助和沟通卡，场景准备区可直达收藏或常用场景。

## 2.4：液态玻璃外观

iOS 26 及以上的导航和操作控件使用原生 Liquid Glass。较早系统使用材质或纯色回退；降低透明度或增强对比度时，自定义玻璃改为实色描边。消息、字幕、输入及播放计时使用稳定的阅读底色。

## 2.5：全屏风景首页

进入首页先显示全屏风景。下方可直接开始面对面沟通、双方打字或电话辅助。上滑风景，或点「上滑查看更多功能」，可把同一张图片收成卡片并使用场景准备、沟通卡和底部导航。从紧凑首页下滑或点「全屏风景」可返回。启用减少动态效果时不做连续缩放。

2.6（7）：首页从四城静态图池读取当天五景；全屏/卡片使用同一原片的两种裁切，断网和未覆盖城市显示随包青岛。后端首次安装、更新和接口说明见 ../../wallpaper/README.md。
